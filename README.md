# Mobile Service Suite — сообщество

Этот репозиторий предназначен для публичного обсуждения Mobile Service Suite:
сообщений об ошибках, предложений и идей по развитию.

MSS — Windows-приложение для сервисных центров, работающих с Android- и
Apple-устройствами. Основной код продукта закрыт. Исходный код компонентов,
который должен быть доступен по условиям сторонних лицензий, публикуется
отдельно в организации
[`Mobile-Service-Suite`](https://github.com/Mobile-Service-Suite).

## Перед созданием обращения

1. Убедитесь, что используете актуальную сборку MSS.
2. Проверьте существующие обращения.
3. Удалите из журналов персональные данные, Apple ID, номера телефонов,
   токены, пароли, серийные номера и содержимое клиентских резервных копий.
4. Опишите ожидаемый и фактический результат, версию MSS, Windows и модель
   устройства.

Для ошибок используйте шаблон **Сообщить об ошибке**, для новых возможностей —
**Предложить улучшение**.

## Важно

- Не загружайте сюда IPA/APK, резервные копии, контейнеры MSS и клиентские
  базы данных.
- Не публикуйте сведения об уязвимостях в обычных Issues. Используйте
  приватную кнопку **Report a vulnerability** во вкладке Security.
- Этот репозиторий не является хранилищем исходного кода основной программы.
